# @elo-ui/components

Accessible, framework-agnostic web components for dashboards and admin interfaces, part of [Elo UI](https://github.com/AAMILLERDEV/elo-ui).

```sh
npm install @elo-ui/core @elo-ui/components
```

```js
import '@elo-ui/core/theme.css';
import '@elo-ui/components/button'; // or '@elo-ui/components' for everything
```

```html
<elo-button variant="primary">Save</elo-button>
```

Every component is keyboard-accessible, works with native forms where relevant, and is tested with axe in Chromium, Firefox, and WebKit.

The package ships a [Custom Elements Manifest](https://github.com/webcomponents/custom-elements-manifest) (`custom-elements.json`) for editor tooling.

Using a framework? See `@elo-ui/react`, `@elo-ui/vue`, and `@elo-ui/angular`.
